# EcoDash-African-Logistics
Interactive HTML5 Canvas simulation modelling solar drone logistics across African Terrain battery management, loadshedding, weather and collision based delivery mission
Project description
Across Africa the poor infrastructure , weather , loadshedding makes it difficult to move medical supplies, food and educational resources  to rural communities. EcoDash models this problem as a 2D simulation rather than a traditional game , the drones movement is driven by trigonometry AND physics
